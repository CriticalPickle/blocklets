Blocklets
=======
The Blocklets mod aims to help players by speeding up various repetitive or grindy parts of Minecraft by providing 
customizable helper mobs that are one block tall. These helpers are called Blocklets, which contain a center block core 
and a tool slot. They can handle various actions for the player, such as mining or fighting. Change their block core to 
provide them with special attributes or provide a more personalized style. In addition, supply them with the correct tool 
for them to work on a specific task. Blocklets are reliable and heavily customizable to meet the varying needs of the player
and their existing world.

This mod is currently only developed and maintained for Minecraft [NeoForge](https://neoforged.net/) in version 1.21.1 (this github branch).

Please view the [wiki](https://github.com/CriticalPickle/blocklets/wiki) for more details on features and other useful 
information, such as how to modify various mod aspects through tags.

Any issues found can be reported [here](https://github.com/CriticalPickle/blocklets/issues).
